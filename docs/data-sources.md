# 数据来源与划分

本轮只读取公开笔迹坐标与标注，没有使用任何第三方识别模型、商业 API、图片 OCR 或手写笔硬件信息。

- 数据：CROHME 2013 TrainINKML，归档名 `CROHME_full_v2.zip`。
- 下载镜像：https://github.com/ThomasLech/CROHME_extractor/tree/master/data
- 文件大小：63,378,013 字节。
- SHA256：`f9fcbaece8410c76c7fe4c47c15702f0d5e7aa572737805b2e2af596e7de7f75`。
- 原始许可声明保存在 `CROHME-original-notices.txt`。归档总说明写明 CC BY-NC-SA 3.0，各子集保留原版权，2013 子目录另有非官方归档不得分发说明。
- 本地权重只用于本轮研究验证；不能把“代码自己写的”当成训练数据已获得商用授权。产品版需改用自有或明确授权的数据重新训练。没有对外分发归档、数据或权重。

共读取并保留 7,246 条有分组/结构标注的唯一表达式，训练/验证/测试为 5,605 / 1,288 / 353。按完整笔迹坐标 SHA256 去重。

分组划分：有 writer 字段时按“来源＋作者 ID”；无该字段时按来源文件会话代理分组。4,253 条表达式有明确 writer 信息。代理不保证不同会话绝不属于同一作者，因此不能宣称整个划分严格跨作者。

这不是 CROHME 官方比赛测试成绩，而是从公开训练归档中自行划出的研究评测。训练、验证、测试的组 ID 与精确笔迹指纹互不相交。测试集只在最终选定模型后使用，不据其结果继续调参。

原始 MathML 和符号分组仅用于离线训练、诊断与评测；实际命令行和 HTTP 识别只接收分笔坐标。演示 JSON 中的 `expected_latex` 不会进入识别器。

难负例只从训练划分挖掘，来源指纹保存在 `reports/hard-negative-provenance.json`。合并与缺笔负例用于学习拒识，不能替代自然书写样本。
